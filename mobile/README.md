# Player Mobile/TV (planejado)

Este diretório será usado para o aplicativo dedicado de reprodução.

## Proposta inicial
- React Native (Expo) para prototipação rápida.
- Foco em Android TV/TV Box.
- Modo tela cheia.
- Cache local de mídia com sincronização automática.
- Suporte a URL de stream (ex.: YouTube Live).

Quando formos iniciar o app, definiremos:
1. Se o alvo é Android TV ou tablet conectado na TV.
2. Dependências específicas para reprodução de vídeo.
